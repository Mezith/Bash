# Bash Scripts Collection
A curated collection of Bash scripts I’ve written for automation, system maintenance, server management, and general Linux workflow improvements.

This repository serves as a central home for all my Bash‑based tooling — from small utilities to full automation pipelines. Each script is self‑contained, documented, and designed to be easy to understand, modify, and extend.

# Purpose
This repo exists to:
- Organize all my Bash scripts in one place
- Provide reusable tools for system administration and automation
- Showcase practical scripting techniques
- Serve as a reference for future projects
- Track improvements and version history over time
